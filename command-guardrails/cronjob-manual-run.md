# CronJob 수동 실행 절차서

## 사전 확인
1. 동일한 CronJob에서 실행 중인 Job이 없는지 확인한다.
2. 중복 실행 시 데이터가 중복 처리되지 않는지 확인한다.
3. 실행 대상 환경과 Namespace를 확인한다.

## 실행
1. CronJob에서 고유한 이름의 일회성 Job을 생성한다.
2. Job의 완료 상태를 기다린다.
3. Job 로그를 확인한다.

## 사후 검증
1. Job의 종료 코드와 처리 결과를 확인한다.
2. 중복 리소스 또는 부작용이 없는지 확인한다.
3. 필요하면 테스트 Job을 정리한다.
